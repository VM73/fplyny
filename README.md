# F-plyny Přeškolení

Mobilní appka pro přípravu na přeškolení F-plynů (kat. I/II → A1/A2, nově B a C podle nařízení (EU) 2024/573).
Učení s opakováním chyb, zkouška nanečisto, kartičky, praxe, tahák a výpočty. Pokrok se po přihlášení synchronizuje přes Supabase.

Běží na GitHub Pages: https://vm73.github.io/fplyny/

Nejde o oficiální zkušební otázky.
